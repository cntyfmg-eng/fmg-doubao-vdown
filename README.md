# fmg-doubao-vdown

豆包视频无水印下载器：下载+Telea修复去AI生成水印+自动验证

## 功能

详见 `SKILL.md`。本仓库是一个 WorkBuddy Skill，包含可复用的工作流与脚本。

## 文件结构

```
.
├── SKILL.md            # Skill 定义(入口)
├── icon.png            # 图标
├── references/         # 参考模板/资料
├── scripts/            # 自动化脚本
├── README.md
├── LICENSE
└── .gitignore
```

## 安装方式

将本仓库内容放入 WorkBuddy 的 skills 目录(`~/.workbuddy/skills/fmg-doubao-vdown/`), 重启或刷新即可。
